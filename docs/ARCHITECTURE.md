# Архитектура Slipstream

## Основные компоненты

1. **Injector:**
   Компонент, отвечающий за внедрение кастомного обработчика в Netty-пайплайн каждого игрока. Слушает события входа и безопасно вставляет `ChannelDuplexHandler` перед дефолтным `packet_handler`.
   
2. **Packet Handler:**
   Асинхронный обработчик Netty канала, перехватывающий `channelRead` (входящие пакеты) и `write` (исходящие пакеты). Вся обработка происходит с учетом корутин, чтобы не блокировать Netty EventLoop.

3. **Bytecode / NMS Bridge:**
   Мост для доступа к полям пакетов без рефлексии. Использует Paperweight NMS маппинги и Kotlin inline classes для достижения Zero-Allocation.

## Принципы разработки (KISS & SOLID)
- **KISS:** Публичный API должен быть предельно простым и понятным (например, `player.sendPacket(packet)`, `val packet = awaitPacket()`).
- **SOLID:** Разделение логики инъекции, обработки пакетов, логирования и анализа на отдельные независимые модули.
